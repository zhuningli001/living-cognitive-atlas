# Tester Invitation

Use this invitation for a 3-5 person external MVP test.

## Short invite

Hi, I am testing an early local-first Chrome extension called Chrome Memory Mirror.

It reads your Chrome bookmarks after you install it and click `Scan bookmarks`, then turns them into a compact personal information profile. The goal is not to organize bookmarks mechanically, but to see whether saved links can become a useful personal memory and self-portrait surface.

This is an unpacked MVP, not a Chrome Web Store release. It does not upload bookmark data, does not read page contents or browser history, and does not edit your bookmarks.

If you are comfortable testing with your Chrome bookmarks, I would love 15-20 minutes of feedback on whether install, scan, report, feedback, rule approval, and reset feel understandable.

## What to send testers

- The `chrome-memory-mirror-v0.1.1-unpacked.zip` package.
- `TESTER_README.md`.
- `TESTER_CHECKLIST.md`.
- A link to GitHub Issues using the `Extension test feedback` template.

## Tester expectations

- Testers should use a Chrome profile they are comfortable testing with.
- Testers should not post exported snapshots, private URLs, personal folder names, or sensitive screenshots publicly.
- Testers should focus on product friction and profile quality, not perfect taxonomy correctness.
- Testers should clear local extension data after testing if they do not want the snapshot retained in Chrome extension storage.

## Follow-up message

Thank you for testing. The most useful feedback is:

- where you hesitated
- what felt trustworthy or untrustworthy
- which profile signal felt accurate
- which profile signal felt wrong, broad, or overconfident
- whether the feedback/rule loop made sense
- whether you would open the extension again later

Please avoid sharing private bookmark URLs or exported snapshot files.
